Project Overview & Architecture

Edge AI Based Smart Surveillance

Transforming conventional passive CCTV systems into active, intelligent sentinels. By attaching an edge computing device directly to the camera, the system analyses video frames locally in real-time, detects specific targets (Person, Dog, Cat, and Cow), sounds local alerts, and records event-triggered clips without depending on the cloud[cite: 3, 4, 10].

System Pipeline & Layers

1. Sensing Layer

Captures live video streams using a dedicated Pi Camera Module (CSI) or standard USB webcam connected directly to the hardware board[cite: 5, 6].

2. Intelligence Layer

OpenCV resizes frames and passes them to the on-device YOLOv8n neural network running locally on CPU to predict bounding boxes and confidence scores[cite: 5, 7].

3. Response & Storage

Filters detections strictly for target classes, records 4-second event clips onto local storage, and logs entries into an SQLite database viewable via Flask[cite: 3, 4].

Hardware Specification

  • Raspberry Pi 4 Model B (4GB) Edge Processing Unit[cite: 6]
  • Pi Camera Module / USB Webcam Live Video Capture[cite: 6]
  • Active Buzzer Module Instant Local Deterrent[cite: 6]
  • MicroSD Card (32GB, Class 10) OS & Clip Storage[cite: 6]

Software Stack

  • Raspberry Pi OS / Python 3 Operating Environment[cite: 7]
  • OpenCV Video Capture & Processing[cite: 7]
  • YOLOv8n / Ultralytics Edge Object Detection[cite: 7]
  • Flask & SQLite Web Dashboard & Database

Why Edge AI Beats Traditional Cloud Systems

Offline Independence Works fully without constant internet connectivity. Detection and local alarms continue uninterrupted[cite: 10].
Enhanced Privacy Video footage stays local on your own device; raw video is never uploaded to third-party cloud servers[cite: 10].
Minimal Storage Discards uneventful frames and stores only short event-triggered clips, preventing storage bloat[cite: 10].
